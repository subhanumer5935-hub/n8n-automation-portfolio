# n8n Automation Portfolio

Portfolio of AI-powered business process automations built with n8n — real, working workflows solving operational problems for e-commerce, property management, and other service businesses.

Built and maintained by **Subtech Automation**.

## Projects

### E-commerce Inbox Triage Bot (v1)
Reads incoming customer support emails, classifies them as order status, refund/complaint, or product question using Gemini AI, auto-replies to order status inquiries, and logs refund/complaint tickets to a tracking sheet for manual follow-up.

**Stack:** n8n, Gmail API, Google Gemini 3.6 Flash, Google Sheets
